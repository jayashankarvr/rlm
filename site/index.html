Keep one app from taking the whole machine

rlm sets memory, CPU and I/O limits on your own Linux processes, without root. Its optional guard freezes or caps a runaway app under memory pressure, instead of letting the desktop lock up.

What it does

  • Start a program with limitsrlm run --memory 2G --cpu 200% -- cargo build runs the build with at most 2 GB of memory and two cores.
  • Limit something already runningBy PID, by name, or a whole application with every process in one shared limit.
  • Profiles and rulesSave named sets of limits, or a rule that applies to an app every time it starts.
  • A desktop app toorlm-gtk does the same from a GTK window: pick an app, set limits, apply.

rlm uses cgroup v2 through systemd's per-user delegation, so it only ever touches your own processes.

Install

  1. Add the signing key 
    sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://jayashankarvr.github.io/rlm/rlm-archive-keyring.gpg | sudo tee /etc/apt/keyrings/rlm.gpg >/dev/null
  2. Add the repository 
    echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/rlm.gpg] https://jayashankarvr.github.io/rlm stable main" | sudo tee /etc/apt/sources.list.d/rlm.list
  3. Install 
    sudo apt update
sudo apt install rlm rlm-gtk

The desktop app, rlm-gtk, needs Ubuntu 24.04 or Debian 13 or newer; rlm alone works from Ubuntu 22.04 and Debian 12. Updates arrive with apt upgrade. Log out and back in once after the first install.

Download the .rpm files from the latest release, then:

With Rust 1.87 or newer:

cargo install rlmctl

This installs rlm and rlm-guard. Run rlm doctor to check that your system delegates the cgroup controllers rlm needs. The desktop app comes with the distribution packages.

The guard

When memory runs short, Linux usually freezes the whole desktop for minutes and then kills something. rlm-guard steps in earlier and more gently.

  • It acts when apps stall on memory and free memory is below 20%, or at once below 400 MB.
  • It freezes the app that is growing for 5 seconds, then caps it with a soft limit if pressure stays high.
  • A cap is lifted after 30 seconds of calm. It never sends a signal to any process.
  • Your desktop, shells, terminals and audio are never frozen, and it holds at most 3 apps at a time.

Turn it on with rlm guard enable, or with the switch on the Guard page of the desktop app. See what it did with rlm guard history.
