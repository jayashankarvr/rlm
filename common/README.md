# rlmctl-common

Shared types for [rlm](https://crates.io/crates/rlmctl): limit parsing (memory, CPU, I/O), profiles, and the config file format, including the `rlm-guard` settings and their validation.

This crate is an internal part of rlm and its API may change between minor versions. To use rlm, install the command-line tool:

```
cargo install rlmctl
```
